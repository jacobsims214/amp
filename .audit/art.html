D1 · CRITICAL

TaskDrawer clipped at every phone width

components/TaskDrawer.tsx:166 · fixed w-[520px]

At 320px the drawer renders at left:-200px and the page cannot scroll horizontally (docScrollW=320), so the ticket title, assignee and the start of every line are unreachable. At 390/430px it is still clipped on the left (title starts mid-word). Fix: full-width sheet on small screens — w-full sm:w-[520px]. Sequence after #3013 (it also edits TaskDrawer.tsx).

D2 · HIGH

Project tab bar cut off, no affordance

components/ui/PageHeader.tsx:33 · overflow-x-auto · scrollW 789 vs clientW 390

The 8 project tabs (Mission→Settings) overflow; the strip scrolls but has no fade or partial-tab cue, and the visible set ends mid-"FLIGHT PLAN" with "Settings" 371px off-screen. Users can't discover Graph/Reports/Artifacts/Library/Settings. Fix: right-edge fade + active-tab-into-view, or collapse to current view + "more".

D3 · HIGH

Board is a 1240px kanban grid

pages/Board.tsx:34-36,432 · LABEL_COL 240 + 5×TASK_COL 200

Fixed-width kanban tuned for 13-inch screens. On a phone it needs sustained horizontal panning; epic names truncate and state columns (SCHEDULED, Ready…) are reached only by swiping. Fix: stacked list on <md (epic→story→full-width cards, state as a chip) instead of squeezed kanban.

D4 · MEDIUM

Board action buttons 19–20px

pages/Board.tsx:470-570 · p-1 on 14px icon

Epic/story "+ add" and "⋯ actions" buttons measure 19–20 CSS px (10 on one board); WCAG/HIG target is 44px, and adjacent controls invite mis-taps. Fix: ≥40px hit area via padding or expanded ::before region.

D5 · MEDIUM

Persistent 10–10.5px text

board code chip, Unassigned, Person·External/Approval badges

10–10.5px labels carry meaning (assignment / performer type) but sit below the mobile readability floor. Fix: raise to ≥12px or icon+accessible-name on <sm.

D6 · LOW–MED

Flight-plan readouts overlap

pages/FlightPlan.tsx:200 · Readouts without wrap

Five equal readout columns at 390px; "DEPENDENCIES"/"LONGEST CHAIN"/stage labels collide. The 3-per-row phone rule only applies when wrap is passed (Mission passes it; FlightPlan doesn't). Fix: pass wrap (one line).
